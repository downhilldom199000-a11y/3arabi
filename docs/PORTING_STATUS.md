## Legend

- ✅ YES = fully ported, .sky package shipped in `dist/`
- ⏳ EASY/MEDIUM/HARD = pending port; see `docs/PORTING_GUIDE.md` for the methodology
- ⏳ BLOCKED = cannot be ported without a SkyStream platform change
- `partial*` (CimaClub sources) = embed URLs are emitted as StreamResults but the original used CloudStream's ExtractorApi which SkyStream lacks; plays direct URLs only
- `—` = not applicable (e.g. no subtitles on this provider)
